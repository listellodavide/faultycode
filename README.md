# Code Review & Refactoring Practice Project

Welcome to Spring Boot Faulty Code Base to learn how to conduct professional code reviews and perform refactoring!  
This repository intentionally contains **faulty, poorly structured, and intentionally problematic code**.

## Purpose of This Repository

This codebase is **not meant to be used in production**.  
Instead, it exists for one purpose:

### Learning how to conduct professional code reviews and perform refactoring

The project includes common real-world issues you may encounter in legacy or rushed codebases, such as:

- ❌ Bad or unclear architecture
- ❌ Security flaws (SQL injection, XSS, double-spending/replay attacks, etc.)
- ❌ Missing or incorrect documentation
- ❌ Non-existent or broken unit tests
- ❌ Performance bottlenecks (slow algorithms, inefficient SQL queries, etc.)
- ❌ Bugs and edge cases
- ❌ Over-complicated or duplicated logic
- ❌ Anti-patterns and bad naming conventions

All of these issues are *deliberate*.  
This repo acts as a safe sandbox to:

- Practice identifying problems
- Explain the impact of each problem
- Recommend improvements
- Apply structured professional refactoring
- Improve your engineering leadership and technical communication skills

## Ideal Use Cases

This repository is perfect for:

- Practicing **code review interviews**
- Pair programming
- Studying real-world refactoring scenarios
- Improving architectural thinking
- Teaching juniors how to analyze code quality
- Preparing for senior/principal engineering roles

## Disclaimer

This repository **must not** be used as sample production code.  
It is intentionally “bad” to help engineers learn how to make it “good”.
